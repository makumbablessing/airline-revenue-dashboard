# ✈️ Airline Revenue Dashboard

## 📖 Overview

This project is an interactive Power BI dashboard that analyzes airline revenue and operational performance using a simulated airport dataset.

The dashboard provides insights into revenue, profit, cargo movement, passenger numbers, fuel costs, and airline performance through interactive visualizations and filters.

## 🚀 Features

- Total Revenue KPI
- Total Profit KPI
- Total Cargo KPI
- Total Passengers KPI
- Revenue by Airline
- Revenue by Destination
- Revenue by Aircraft Type
- Fuel Cost Analysis
- Profit Analysis
- Interactive Filters (Airline, Aircraft Type, Destination, Revenue Type, Month)

---

## 🛠️ Tools Used

- Microsoft Power BI Desktop
- Power Query
- Microsoft Excel

---

## 📂 Dataset

The dataset contains 500 simulated airline records with the following fields:

- Flight Number
- Date
- Airline
- Aircraft Type
- Origin
- Destination
- Revenue Type
- Passengers
- Cargo (kg)
- Revenue (KES)
- Fuel Cost (KES)
- Profit
