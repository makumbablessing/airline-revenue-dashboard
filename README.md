#  Airline Revenue Dashboard

## 📖 Overview

The **Airline Revenue Dashboard** is an interactive Power BI project developed to analyze airline operational and financial performance. The dashboard transforms raw airport data into meaningful business insights using **Power BI Desktop**, **Power Query**, and **DAX**.

It enables users to monitor key performance indicators (KPIs), compare airline performance, analyze cargo and passenger traffic, evaluate fuel costs, and identify revenue trends through interactive visualizations.

This project demonstrates practical Business Intelligence techniques used to support data-driven decision-making within the aviation industry.

---

# Business Problem

Airport management teams and airline executives require quick access to operational and financial data to monitor business performance and make informed decisions.

Without a centralized dashboard, it is difficult to:

- Track airline revenue
- Monitor operational costs
- Compare airline performance
- Analyze passenger traffic
- Evaluate cargo movement
- Identify profitable routes and aircraft

This dashboard provides a single interactive report that answers these business questions.

#  Dataset

The project uses a simulated airport revenue dataset containing over **500 records**.

The dataset includes:

- Flight Number
- Date
- Airline
- Aircraft Type
- Origin
- Destination
- Revenue Type
- Passengers
- Cargo (kg)
- Revenue (KES)
- Fuel Cost (KES)

A calculated **Profit** field was created during data transformation.

---

#  Data Preparation

The dataset was transformed using **Power Query** before building the dashboard.

Data preparation included:

- Checking data types

- Creating a Profit column
