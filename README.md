#  Airline Revenue Dashboard

An interactive **Power BI dashboard** designed to analyze airline revenue, operational performance, cargo movement, passenger traffic, and fuel costs.

This project demonstrates how Power BI can transform raw operational data into meaningful business insights through interactive dashboards and visual analytics.

---

##  Business Problem

Airport management teams need quick access to operational and financial performance to support decision-making.

This dashboard was created to answer questions such as:

- Which airline generates the most revenue?
- Which destinations perform best?
- How much cargo is transported?
- How many passengers are served?
- How profitable are airline operations?
- How do fuel costs impact profitability?
